```
location   {ledgerTag, topicId}                   a proof's own meaning.uri
locator    {ledgerTag, topicId, sequenceNumber}   one message
           {ledgerTag, txRef}                      one transaction
```

## What was wrong in the plan as approved

**The 2026-09-08 probe token is not reusable.** `0.0.10425740` holds 9,999 units of `0.0.10425743` and its private key was born in that run's process and discarded — it is in no file, by design. Nothing can move those units, including us. That is the strongest sense in which a probe token can be inert, and it is what CLAUDE.md §11's "where reusable" was hedging against. This probe minted its own token with its own throwaway treasury and left a second permanently inert token behind for the same reason the first one is.
