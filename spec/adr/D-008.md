## Context

Faster, tracked, insured: real postal services have tiers, and Q-11 asked whether WISHMail should.

## Decision

Weight is the only tier this specification defines. A service class is declared as a competitive tier and given no definition here. RECORD.

## Alternatives considered

- Define classes now — rejected: nothing in the window needs them, and each would need its own price rule under P-11.

## Consequences

§4.2 makes weight the only scale; §4.7 names service classes as a competitive tier; §19.3 says what would close Q-11 (an extension that prices the class above the stamp and never below, keeping P-11 for the stamp itself).
