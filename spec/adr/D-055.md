## Context

A proof carried by reference (D-26) needs somewhere to be dereferenced from, and that somewhere has to be on consensus before the envelope that names it.

## Decision

The record, from ledger §B row D-55, verbatim:

> *(amended by D-73)* The resolution proof's manifest is published on a dedicated per-agent manifest topic before `send`; locators are structured `{ledgerTag, topicId, sequenceNumber}`.

## Alternatives considered

- None recorded. The ledger §B row states the decision without a fork; where a fork was closed, the row says so.

## Consequences

The manifest is published before `send` and locators are structured `{ledgerTag, topicId, sequenceNumber}`, never strings — the HCS-1 HRL grammar names files, not messages (§5.2). Amended by D-73, which gave every agent a dedicated manifest topic rather than using the outbound log.
