## Context

An agent might already hold Hedera keys or might never have touched Hedera, and both had to be able to send mail without the Postmaster ever holding a secret.

## Decision

The record, from ledger §B row D-54, verbatim:

> Provisioning has two configurations — self-provisioned (BYOK) and Postmaster-provisioned — and in both the private keys are born in the agent's process and never leave. No path in which the Postmaster generates or transmits private keys.

## Alternatives considered

- A path in which the Postmaster generates and transmits keys — rejected outright: it is P-13, and no convenience buys it back.

## Consequences

Two configurations, both conforming: self-provisioned (bring your own keys and ask the Postmaster for nothing but stamps) and Postmaster-provisioned (generate keys in your own process, submit the public halves, receive coordinates). In both the private keys are born where the agent runs and stay there (§4.6, T-P13-1, T-P13-2).
