## Context

Code written before the specification it implements makes the specification a description of the code.

## Decision

The repository is outfitted — layout, DCO, Conventional Commits, CHANGELOG, ADRs, schemas, pins — before any implementation is written. RECORD.

## Alternatives considered

- Build first, write the spec from what was built — rejected: it inverts the chain of custody D-11 sets up.

## Consequences

No normative sentence; it is the working order the whole repository is built in, restated in CLAUDE.md §4 and STATUS.md §3 step 0. This ADR backfill is itself performed under it.
