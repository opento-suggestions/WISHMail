## Context

A broker can say more about an agent than the ledger records. The question is what a Verifier does with the surplus.

## Decision

A proof sourced through a broker is appraised at or below what was declared, never above. A downgrade is permitted; an upgrade is forbidden. RECORD.

## Alternatives considered

- Let a broker's corroboration raise a standing — rejected: it makes the broker an authority, which is P-4 and P-6 both.

## Consequences

Becomes the governing clause of P-12 and §11.4's rule that a Verifier does not raise a trust class or remove an endorsement. §9.5 applies it: what the broker returns is not an input at all.
