## Context

Two Verifiers reading the same topics must reach the same state, which means every ambiguity a lane can present has to be resolved by a rule and not by judgement.

## Decision

The record, from ledger §B row D-67, verbatim:

> Verifier derivation rules (§8.5): canonical chunk = earliest per (id, i); `n`/`h` are chunk 0's; a settlement counts only if it exists, memo matches, `to` is the treasury, and it precedes chunk 0 in consensus time (late settlement = unstamped, strict); receipt = earliest, counts only on a SETTLED envelope standing verified/unverified; an unrequested receipt counts and is noted.

## Alternatives considered

- None recorded. The ledger §B row states the decision without a fork; where a fork was closed, the row says so.

## Consequences

§8.5 fixes the canonical chunk, the counted settlement, and the counted receipt, and derives state from the three. A settlement counts only if it exists, its memo matches, its `to` is the treasury, and it precedes chunk 0 — so a late settlement does not count and the envelope is unstamped: paying after posting is not postage. T-P3-2's exception corpus is built from this section.
