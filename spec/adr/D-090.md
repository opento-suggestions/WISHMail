## Context

HCS-13 has two locator forms, and the unpinned one names whatever version is latest — which would make a chunk's declared schema change under it.

## Decision

The record, from ledger §B row D-90, verbatim:

> `schemaRef` is HCS-13's version-pinned HRL, `hcs://13/<topicId>#<sequenceNumber>` — the HCS-2 topic managing the schema and the register operation's sequence number (FETCHED 09-05, hol.org/docs/standards/hcs-13, Status: Draft). The unpinned form is never a `schemaRef`. §5.11 amended (`CHANGED`).

## Alternatives considered

- None recorded. The ledger §B row states the decision without a fork; where a fork was closed, the row says so.

## Consequences

FETCHED 2026-09-05: `schemaRef` is HCS-13's version-pinned locator `hcs://13/<topicId>#<sequenceNumber>` — the HCS-2 topic managing the schema and the sequence number of the register operation. The unpinned form `hcs://13/<topicId>` names the latest version and **is never a `schemaRef`** (§5.11, T-P9-3). A Verifier that cannot resolve one reports `VERIFY_SCHEMA_UNRESOLVED` and appraises unverified; it does not guess.
