## Context

§9.1's T-P6-2 tests replay for every profile, and a profile rule's own failure branches — a malformed memo, a missing record, a disagreeing identifier — were untested.

## Decision

The record, from ledger §B row D-99, verbatim:

> Every profile rule carries its own `Conformance:` line: §9.2 T-P6-3, §9.3 T-P6-4 (§9.4 T-P6-2 from D-97). §9.1's T-P6-2 remains the replay test for all profiles; the per-profile tests cover the rule's failure branches. Sonic 09-06.

## Alternatives considered

- None recorded. The ledger §B row states the decision without a fork; where a fork was closed, the row says so.

## Consequences

Every profile rule carries its own `Conformance:` line: §9.2 T-P6-3, §9.3 T-P6-4, §9.4 T-P6-2, §9.5 T-P6-5. §9.1's T-P6-2 remains the replay test for all profiles; the per-profile tests cover each rule's failure branches. This is what brought P-6's test range to T-P6-1 – T-P6-5 in D-115.
