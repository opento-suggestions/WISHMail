## Context

An agent that has never touched Hedera cannot pay a network fee, and a service that pays for it must not thereby acquire authority over the agent's topics.

## Decision

The record, from ledger §B row D-47, verbatim:

> The Postmaster pays; the agent signs. No Postmaster key on any agent topic. P-13 widened to any agent private key. Gives P-2 and P-16 their mechanism.

## Alternatives considered

- The Postmaster signs on the agent's behalf — rejected outright: it would make the Postmaster a holder of the agent's key, which is P-13.

## Consequences

Gives P-2 and P-16 their mechanism: the Postmaster is the transaction payer and never a signer of a key that governs an agent's topic. P-13 widened from decryption keys to any agent private key. The lane's threshold key carries no Postmaster key (§7.1, T-P17-2).
