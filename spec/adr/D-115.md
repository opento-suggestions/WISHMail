## Context

## Decision

The record, from ledger §B row D-115, verbatim:

> **§12's *Tests:* ranges brought current** (`CHANGED`), a seam found while applying D-113: P-6 → T-P6-1 – T-P6-5 (D-99, D-104 added per-profile tests); P-9 → T-P9-1 – T-P9-11 (D-95's T-P9-10 was never listed; T-P9-11 now core); P-11 → T-P11-1 – T-P11-6 (§14); P-13 → T-P13-1 – T-P13-4 (D-106, D-110). ## Alternatives considered

- None recorded. The ledger §B row states the decision without a fork; where a fork was closed, the row says so.

## Consequences

Ranges brought current: P-6 → T-P6-1 – T-P6-5 (D-99 and D-104 added per-profile tests); P-9 → T-P9-1 – T-P9-11 (D-95's T-P9-10 was never listed, and T-P9-11 is now core); P-11 and the rest checked with them. §12 is the key every test reads backward, so a stale range there is a test nobody can find from its invariant.
