## Context

An agent has to be findable and resolvable on Hedera without a broker in the path.

## Decision

The native surface is an HCS-11 profile declaration with an HCS-2 directory, named explicitly in the specification rather than left to the implementation. RECORD; later BUILD under D-23.

## Alternatives considered

- Leave the native surface to the implementation — rejected: it is the profile that makes P-4 achievable.

## Consequences
