## Context

P-12 needs a vocabulary for what a proof's verification terminates in, and the build was only going to implement two of the four kinds.

## Decision

The record, from ledger §B row D-63, verbatim:

> Trust classes: all four in the vocabulary; the build appraises `math` and `social-committee`. TEE's hooks are §16: TRACE Trust Record handoff by certified mail; key-custody attestation on an HCS-11 profile (Q-3).

## Alternatives considered

- None recorded. The ledger §B row states the decision without a fork; where a fork was closed, the row says so.

## Consequences

All four trust classes enter the vocabulary — `math`, `economic-game`, `hardware-TEE`, `social-committee` (§2.2) — so that a profile can declare honestly even where this release appraises only `math` and `social-committee`. The TEE hook became §16.3's key-custody attestation, declared and not built.
