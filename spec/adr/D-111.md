## Context

An extension with no place to be named would bind every reader or none, and §16 needed a switch.

## Decision

The record, from ledger §B row D-111, verbatim:

> The ConformanceClaim carries `extensions [string]` (§5.10); an extension binds only a release that names it there (§16.1).

## Alternatives considered

- None recorded. The ledger §B row states the decision without a fork; where a fork was closed, the row says so.

## Consequences

The `ConformanceClaim` carries `extensions [string]` (§5.10), and an extension binds only a release that names it there (§16.1). This is what makes the five extension tests — T-P2-3, T-P5-5, T-P6-6, T-P11-7, T-P12-7 — bind conditionally rather than always, and why `conformance/` builds them last or not at all.
