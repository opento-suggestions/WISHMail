## Context

## Decision

The record, from ledger §B row D-58, verbatim:

> Tool names frozen by §6: `resolve`, `buy_stamp`, `send`, `inbox`, `ack`, `verify`. Q-9 closes.

## Alternatives considered

- None recorded. The ledger §B row states the decision without a fork; where a fork was closed, the row says so.

## Consequences

Six names frozen: `resolve`, `buy_stamp`, `send`, `inbox`, `ack`, `verify`. Closes Q-9. Failure codes are `TOOL_REASON` built on them (§6). The names are the vocabulary rule of CLAUDE.md §4: no synonyms anywhere in the repository.
