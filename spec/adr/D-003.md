## Context

WISHMail needed a surface an agent could actually call, and a judge could actually see.

## Decision

The tool surface is delivered over MCP. The WebMCP page is the primary human-visible surface; the MCP server exposes the identical tool schema as a second transport. RECORD.

## Alternatives considered

- A REST API only — rejected: not an agent surface.
- A CLI only — rejected: not demonstrable to a judge.

## Consequences

Becomes §6.1's "every transport exposes the same schema" (T-P15-4) and §18.5's app/ layout. Which of the two holds the x402 402-state was decided later, against this one's "primary": D-109 makes the MCP server the resource server and the page its client. D-124 records that WebMCP is unpinned and unsurveyed by choice.
