## Context

§1.6 had listed the HOL broker's API among the pins, which would have made a private service a dependency of conformance.

## Decision

The record, from ledger §B row D-103, verbatim:

> §1.6: the HOL row no longer names a broker API — the broker is a directory, not a dependency; the anchor topics are listed in §9.5 as deployment facts.

## Alternatives considered

- None recorded. The ledger §B row states the decision without a fork; where a fork was closed, the row says so.

## Consequences

The HOL row names no broker API. The broker is a directory, not a dependency; the anchor topics are listed in §9.5 as deployment facts. P-4 is what this protects: nothing a claim rests on may require a private service. The anchors are reproduced in `spec/pins.json` under `registryAnchors` with a note saying exactly this.
