## Context

An HCS-11 account memo can point straight at a profile file, and a memo's past values are not re-obtainable from any mirror node — so a resolution made under an old declaration could not be appraised later.

## Decision

The record, from ledger §B row D-70, verbatim:

> The native declare surface requires the HCS-2 indirection: account memo `hcs-11:hcs://2/<registry>`, one entry per profile version, so declarations at any past consensus time remain resolvable (F-8 Verifier side; `math` means forever). A memo pointing straight at an HCS-1 file does not resolve.

## Alternatives considered

- None recorded. The ledger §B row states the decision without a fork; where a fork was closed, the row says so.

## Consequences

A declaring agent MUST set its memo to `hcs-11:hcs://2/<registryTopic>` and register each profile version there, so that declarations at any past consensus time stay resolvable and `math` means forever (§9.2, T-P8-3). HCS-11 permits the HCS-2 form by example and by list, not by MUST, and leaves which entry is 'the profile' unspecified — WISHMail fixes it (recon O-3). D-107 later admits the direct form for *reading*, endorsed `blurred`.
