## Context

HCS-10's connection-topic memo marks the topic non-indexed — a hint that only the latest message matters — and an envelope is many messages.

## Decision

The record, from ledger §B row D-95, verbatim:

> **Lanes are read in full whatever the memo says.** HCS-10's connection-topic memo is `hcs-10:1:{ttl}:2:{inboundTopicId}:{connectionId}` — `indexed=1`, "only the latest message should be read." Strict HCS-10 keeps the memo; WISHMail's reading rule overrides the hint for its own readers. §7.1 amended (`CHANGED`); T-P9-10. MINE, closed by Claude under P-9 + §11.3; Sonic may reopen.

## Alternatives considered

- None recorded. The ledger §B row states the decision without a fork; where a fork was closed, the row says so.

## Consequences

Strict HCS-10 keeps the memo; WISHMail's reading rule overrides the hint for its own readers. An Inbox and a Verifier MUST read **every** message on a lane in scope, whatever the memo indicates (§7.1, T-P9-10). The hint is HCS-10's and the reading rule is this document's — a lane is mail, and every message on it is read.
