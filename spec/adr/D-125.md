## Context

The document was ready to freeze, and the wire strings still carried a version number the release would not be.

## Decision

The record, from ledger §B row D-125, verbatim:

> **Frozen as version 0.5.0** (Sonic 09-07: "Wire strings can move to v0.5 — along with the final 'Wishmail spec v0.5' renaming the fresh document"). Wire strings `"v": "0.5"` (§7.2) and `wishmail/0.5/seal` (§7.3); files renamed `WISHMAIL_SPEC_v0_5.md` / `CONFORMANCE_TESTS_v0_5.md`; the §1 status line states the freeze; the Contents no longer carry landed/drafted marks; nothing is registered yet, so no schema digest changes. 0.4.x is history.

## Alternatives considered

- None recorded. The ledger §B row states the decision without a fork; where a fork was closed, the row says so.

## Consequences

Frozen as **0.5.0**. Wire strings move: the AAD's AAD version field at `0.5` (§7.2) and the HPKE info `wishmail/0.5/seal` (§7.3). Files renamed `WISHMAIL_SPEC_v0_5.md` and `CONFORMANCE_TESTS_v0_5.md`. A wire string carries `major.minor` and nothing finer (D-89), so this was a minor-version move and not a patch.
