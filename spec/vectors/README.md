# spec/vectors/

The test vectors two conformance tests read as their court. Both are **generated by the reference implementation** and are not written by hand. **Both exist**, generated 2026-09-08 and frozen from one run: `npm run vectors` writes them and `npm run check:vectors` recomputes every value in them from the fields they carry.

```
aad.json    §7.2 — header fields, AAD bytes, and `id` for the fixture envelopes.
            The AAD's key names are exactly {p, v, l, lane, rp, nc}, canonical JSON
            per RFC 8785, and its SHA-256 is the envelope identifier (D-53, D-127).
            Court for: T-P1-4 — every class recomputes them exactly.

seal.json   §7.3 — HPKE (RFC 9180) vectors for the fixture envelopes, base mode,
            single-shot, DHKEM(X25519, HKDF-SHA256) / HKDF-SHA256 / AES-256-GCM,
            info "wishmail/0.5/seal" (D-61, D-125).
            Court for: T-P1-5 — the reference seals and an independent implementation
            opens, and the reverse.
```

"Independent" for T-P1-5 means an implementation that does not share the reference's code path. STATUS.md §5 records the intent: a second, minimal implementation of §7.2–§7.3 in another language, inside `conformance/`. It does not exist yet, so T-P1-5 fails like the other eighty-two.

**`seal.json` carries the recipient's private key**, exactly as RFC 9180 publishes `skRm` beside its own vectors, because T-P1-5 requires an independent implementation to *open* what the reference sealed. That key was born for the vector, is bound to no account, topic or epoch, and is no provisioned agent's; the generator refuses any key that appears in `app/deployment/hedera-testnet.json`. P-13 forbids the private key of an **agent**, which this is not (D-151).

`spec/pins.json` records the wire strings these vectors are generated under (`wireStrings`). A release claiming any patch of minor version 0.5 passes T-P1-4 and T-P1-5 against 0.5's vectors (§1.7, T-P9-9) — which is why a change to either wire string is a new minor version and never a patch.
